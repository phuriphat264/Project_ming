# 🏭 ระบบคำนวณต้นทุนและกำไรอัตโนมัติ (Automated Cost & Profit Calculation System)
**กรณีศึกษา:** บริษัท มาตัง คอสเมติก จำกัด (Matang Cosmetic Co., Ltd.)  
**โครงงานสหกิจศึกษา:** สาขาวิชาเทคโนโลยีสารสนเทศและวิทยาการข้อมูล คณะวิทยาศาสตร์และศิลปศาสตร์ มหาวิทยาลัยบูรพา วิทยาเขตจันทบุรี

```

├── core/                       # แกนประมวลผลหลัก (Data Processing Engine)

│   ├── pipeline.py             # Data Pipeline แทนที่ VLOOKUP / SUMIFS
│   ├── metrics.py              # สูตรคำนวณการเงิน, What-If และ Anomaly Detection
│   ├── db.py                   # ฐานข้อมูล SQLite (SKU, Fixed Cost, ผู้ใช้)
│   ├── export.py               # ส่งออกรายงาน Excel (.xlsx) และ PDF Summary
│   └── ui.py                   # ตัวช่วยจัดการ Session, Auth และ UI
├── pages/                      # หน้าจอการทำงานของระบบ (Sidebar Pages)
│   ├── 1_📊_แดชบอร์ด.py         # แดชบอร์ดภาพรวมผู้บริหาร + MoM Comparison + สลับดูงวด
│   ├── 2_📤_นำเข้าข้อมูล.py       # ลากวางไฟล์ Excel TikTok, ตรวจจับข้อมูล, บันทึก Snapshot
│   ├── 3_📦_สินค้าและต้นทุน.py   # หน้าเพิ่ม/ลบ/แก้ไข ราคาทุนสินค้า และต้นทุนคงที่

│   ├── app.db                  # ฐานข้อมูล SQLite (SKU 63 ตัว, ผู้ใช้, ต้นทุนคงที่, ประวัติงวด)
│   └── snapshots/              # แคชข้อมูลรายเดือนแบบบีบอัด Parquet เปิดดูย้อนหลังได้ทันที
└── scripts/
    └── smoke_test.py           # สคริปต์ทดสอบระบบกับไฟล์ Excel จริงทั้งหมด
```

## 🚀 วิธีเปิดใช้งานระบบ

### บนเครื่อง Mac / Linux:
เปิด Terminal แล้วเข้าไปที่โฟลเดอร์โปรเจกต์ จากนั้นรัน:
```bash
cd cost_profit_system
./run.sh
```
หรือรันผ่าน Virtual Environment โดยตรง:
```bash
.venv/bin/streamlit run app.py
```

### บนเครื่อง Windows:
ดับเบิลคลิกไฟล์ `run.bat` ได้ทันที

## 🔐 บัญชีเข้าสู่ระบบเริ่มต้น
| บทบาท | ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | สิทธิ์การเข้าถึง |
|---|---|---|---|
| **ผู้บริหาร / บัญชี (Admin)** | `admin` | `admin123` | เข้าถึงได้ทุกหน้า, ดูตัวเลขกำไรสุทธิ, แก้ไขราคาทุนสินค้าได้ |
| **พนักงาน (Staff)** | `staff` | `staff123` | นำเข้าไฟล์ Excel ได้, ซ่อนตัวเลขต้นทุนและกำไรสุทธิไว้ |

*(สามารถเปลี่ยนรหัสผ่านหรือเพิ่มผู้ใช้ใหม่ได้ที่หน้า **⚙️ ผู้ใช้งาน**)*

## 🌐 การแชร์ใช้งานร่วมกันในโรงงาน (วง LAN / Wi-Fi เดียวกัน)
หากต้องการให้เครื่องอื่นในโรงงานเปิดใช้งานระบบได้ ให้รันคำสั่ง:
```bash
.venv/bin/streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```
จากนั้นเครื่องอื่นในโรงงานสามารถเข้าใช้งานผ่านเบราว์เซอร์ได้ที่:
`http://<IP-เครื่องเรา>:8501` เช่น `http://192.168.1.50:8501`
