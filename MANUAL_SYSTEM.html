ส่วนที่ 1: ขั้นตอนการติดตั้งและเปิดใช้งานระบบ (Installation & Launch)

1.1 สิ่งที่ต้องเตรียมก่อนเริ่มใช้งาน (Prerequisites)

  1. เครื่องคอมพิวเตอร์: รองรับทั้ง Microsoft Windows (10 หรือ 11) และ Apple macOS (เวอร์ชัน 12 ขึ้นไป)
  2. โปรแกรม Python: รองรับตั้งแต่ Python 3.9 ถึง 3.12+ (ดาวน์โหลดได้ฟรีจาก https://www.python.org/downloads/)
    • สำคัญมากสำหรับผู้ใช้ Windows: ในขั้นตอนแรกของการติดตั้ง Python ต้องติ๊กเครื่องหมายถูกที่ช่อง "Add python.exe to PATH" ด้านล่างสุดเสมอ เพื่อให้ Windows สามารถเรียกคำสั่งรันระบบได้อัตโนมัติ
  3. การเชื่อมต่ออินเทอร์เน็ต: จำเป็นเฉพาะ การเปิดใช้งานครั้งแรกสุด เพื่อให้ระบบดาวน์โหลดไลบรารีที่จำเป็น (Streamlit, Pandas, Plotly, PyArrow, OpenPyXL, Bcrypt) จากนั้นสามารถใช้งานแบบ Offline ในเครื่องได้

1.2 ขั้นตอนการเปิดใช้งานระบบ (One-Click Launch)

สำหรับผู้ใช้งาน Microsoft Windows:
  1. แตกไฟล์ ZIP โปรเจกต์ลงในเครื่อง (เช่น โฟลเดอร์ C:\Users\...\Downloads\Project_ming-main)
  2. ดับเบิลคลิกที่ไฟล์ run.bat (หรือ START_WINDOWS.bat)
  3. หน้าต่างคำสั่งสีดำจะตรวจสอบ Python และสร้างสภาพแวดล้อม Virtual Environment (.venv) ให้อัตโนมัติ (ครั้งแรกใช้เวลาประมาณ 1-2 นาที)
  4. เมื่อติดตั้งเสร็จ หน้าเว็บเบราว์เซอร์จะเด้งเปิดระบบที่ http://localhost:8501 ขึ้นมาให้ทันที
สำหรับผู้ใช้งาน Apple macOS:
  1. ดับเบิลคลิกที่ไฟล์ START_MAC.command (หรือรันคำสั่ง ./run.sh ใน Terminal)
  2. ระบบจะสร้าง Virtual Environment และเปิดหน้าเว็บเบราว์เซอร์ให้อัตโนมัติ

ส่วนที่ 2: สถาปัตยกรรมข้อมูลและสูตรการคำนวณทางการเงิน (Calculation Engine)

ระบบถูกออกแบบให้สอดคล้องกับโครงสร้างรายงานทางการเงินของ TikTok Shop Seller Center และหลักการบัญชีต้นทุนโรงงาน เพื่อให้ตัวเลขยอดเงินรับและกำไรสุทธิกระทบยอดตรงกับรายการเดินบัญชีธนาคารจริงของ บริษัท มาตัง คอสเมติก จำกัด:

ตัวชี้วัด / คอลัมน์ สูตรการคำนวณที่ใช้ในระบบ คำอธิบายทางบัญชี
1. ยอดเงินโอนสุทธิ (F)
(Net Settlement)		 ยอดขายรวม - ค่าธรรมเนียมแพลตฟอร์ม - โฆษณา GMV ยอดเงินจริงที่ TikTok โอนเข้าบัญชีบริษัท (หัก Transaction Fee, Marketplace Commission, ค่าคอมพันธมิตร และค่าส่งแล้ว)
2. จำนวนสินค้าสุทธิ
(Net Quantity)		 จำนวนสั่งซื้อ - จำนวนคืนสินค้า (Return Qty) นับเฉพาะสินค้าที่ส่งมอบสำเร็จ ไม่นับจำนวนของออเดอร์ที่ลูกค้ายกเลิกหรือส่งคืนสินค้ากลับโรงงาน
3. มูลค่าต้นทุนสินค้า (J)
(SKU Cost Value)		 Net Quantity × ราคาทุนต่อหน่วย (I) ต้นทุนการผลิตจริงของแต่ละ SKU ที่ส่งมอบออกไป (อ้างอิงจากฐานข้อมูลราคาทุนโรงงาน)
4. ต้นทุนรวมคำสั่งซื้อ (G)
(Total Order Cost)		 ผลรวมมูลค่าต้นทุนสินค้า (J) ใน Order นั้น
*พร้อมกลไกตัดซ้ำ (1 COGS per Order ID)		 ระบบป้องกันต้นทุนเบิ้ล: แม้ออเดอร์เดียวกันจะมีหลายรายการสินค้า หรือมีแถวจ่ายคืนค่าส่งย้อนหลัง ระบบจะคิดต้นทุนเพียงครั้งเดียวต่อ 1 ออเดอร์ ป้องกันตัวเลขต้นทุนบวม
5. กำไรจากการขาย (H)
(Profit after Ads GMV)		 ยอดเงินโอนสุทธิ (F) - ต้นทุนรวม (G) กำไรจากการขายหลังหักต้นทุนสินค้าและค่าแอดโฆษณา GMV
6. กำไรสุทธิสุดท้าย
(Net Operating Profit)		 กำไรจากการขาย (H) - ค่าคอมฯ - ค่าใช้จ่ายโรงงาน กำไรสุทธิแท้จริงหลังหักค่าตอบแทนทีมขาย และต้นทุนคงที่ (ค่าแรงพนักงาน, ค่าน้ำ, ค่าไฟ, ค่าเช่า)
7. จุดคุ้มทุน (BEP)
(Break-even Point)		 ค่าใช้จ่ายคงที่รวม ÷ อัตรากำไรส่วนเกิน (Margin %) ยอดขายขั้นต่ำที่บริษัทต้องทำให้ได้ในแต่ละงวดเดือนเพื่อให้คุ้มกับภาระต้นทุนคงที่ของโรงงาน

ส่วนที่ 3: คู่มือการใช้งานระบบรายหน้าจอ (Step-by-Step Guide)

3.1 หน้าหลัก (Home)

แสดงการสรุปภาพรวมผลประกอบการสะสมของบริษัท:

  • การ์ดสรุปจำนวนสินค้า SKU ทั้งหมดในระบบ และจำนวนงวดเดือนที่ประมวลผลไว้
  • ยอดขายสะสมรวมทุกงวด และยอดกำไรสุทธิรวมสะสม
  • ปุ่มทางลัดขนาดใหญ่สำหรับเข้าสู่เมนูหลัก: "📊 ไปหน้าแดชบอร์ด", "📤 นำเข้าข้อมูลยอดขาย", และ "📦 จัดการสินค้าและต้นทุน"

3.2 หน้าแดชบอร์ด (📊 แดชบอร์ด)

กระดานภาพวิเคราะห์ข้อมูลทางการเงินเชิงโต้ตอบสำหรับผู้บริหาร:

  1. กล่องเลือกงวดเดือน: สามารถเลือกดูเฉพาะงวดเดือนที่ต้องการ (เช่น 2026-08, 2026-09) หรือเลือก "📊 สรุปรวมทุกงวดทั้งหมด" เพื่อดูผลประกอบการแบบสะสม
  2. แบนเนอร์ฟันธงสถานะ (Profit/Loss Verdict Banner): แจ้งเตือนชัดเจนด้วยสีเขียว (ไม่ขาดทุน) หรือสีแดง (ขาดทุน) พร้อมระบุจำนวนออเดอร์ที่ขายขาดทุน และยอดขาดทุนรวม
  3. การ์ดสรุปตัวชี้วัดหลัก 4 ใบ:
    • การ์ดที่ 1 (F): ยอดการชำระเงินทั้งหมดที่ได้รับจาก TikTok Shop
    • การ์ดที่ 2 (G): มูลค่าต้นทุนสินค้าทั้งหมดที่จำหน่ายไป
    • การ์ดที่ 3 (H): กำไรจากการขายหลังหักค่าแอดโฆษณา GMV
    • การ์ดที่ 4: กำไรสุทธิคงเหลือหลังหักค่าคอมมิชชั่นและค่าใช้จ่ายโรงงาน
  4. กราฟเปรียบเทียบผลประกอบการรายเดือน (Monthly Comparison): กราฟแท่งเปรียบเทียบ รายได้ · ยอดชำระ F · ต้นทุน G · กำไรสุทธิ โดยจัดแกน X แยกตามเดือนอย่างสวยงาม
  5. กราฟแนวโน้มรายวัน (Daily Financial Trend): แสดงยอดขายและกำไรในแต่ละวัน พร้อมปุ่มสลับดูกำไรก่อนหักแอด และหลังหักแอด GMV
  6. ตารางเช็กรายสินค้า (SKU Analysis): วิเคราะห์ยอดขาย ราคาขายเฉลี่ย ราคาทุนต่อหน่วย และกำไรขั้นต้นของสินค้าแต่ละตัว พร้อมไฮไลต์สินค้าที่ทำกำไรสูงสุดและสินค้าที่ขาดทุน
  7. ตารางตรวจจับออเดอร์ผิดปกติ (Anomaly Detection): แสดงรายการออเดอร์ที่ประสบภาวะขาดทุน เพื่อให้ฝ่ายขายตรวจสอบโปรโมชั่นหรือค่าส่งที่ผิดปกติได้ทันที

3.3 หน้านำเข้าข้อมูล (📤 นำเข้าข้อมูล)

ศูนย์กลางการนำเข้าและประมวลผลไฟล์รายงานจากระบบ TikTok Shop:

  1. การอัปโหลดไฟล์ Excel:
    • ลากและวางไฟล์รายงาน Excel (.xlsx) ที่ดาวน์โหลดจาก TikTok Shop Seller Center ลงในกล่องอัปโหลด
    • ระบบรองรับไฟล์ทุกประเภท: ไฟล์รายละเอียดคำสั่งซื้อ (Order Details), ไฟล์รายการสินค้า (OrderSKUList / Order8 / Order9), ไฟล์สรุปแอด (Ads), และไฟล์สรุปการถอนเงิน (Settlement)
    • ระบบ Auto-Recovery: ตรวจจับแถวหัวตารางและแก้ไขรูปแบบภาษาไทย/อังกฤษให้อัตโนมัติ
  2. การรวมข้อมูลข้ามไฟล์ (Data Merge): สามารถอัปโหลดไฟล์หลายร้านค้าหรือหลายไฟล์ในเดือนเดียวกัน ระบบจะเชื่อมโยงข้อมูลและตัดออเดอร์ซ้ำซ้อนให้อัตโนมัติ
  3. การบันทึกงวด (Save Snapshot): เมื่อตรวจสอบตัวเลขยอดขายและกำไรเรียบร้อย ให้กดปุ่ม "💾 บันทึกงวดนี้ลงระบบ" ข้อมูลจะถูกจัดเก็บเข้าสู่ฐานข้อมูลอย่างถาวร
  4. การจัดการงวดเดิม: ด้านล่างมีรายการงวดเดือนทั้งหมด สามารถกดเลือกเพื่อ "📂 เปิดดูข้อมูลนี้" หรือกด "🗑️ ลบงวดนี้" / "🗑️ ลบข้อมูลทุกงวด" เพื่อล้างข้อมูลออกอย่างสมบูรณ์

3.4 หน้าสินค้าและต้นทุน (📦 สินค้าและต้นทุน)

เมนูสำหรับกำหนดโครงสร้างต้นทุนของโรงงาน (สำหรับผู้ดูแลระบบ):

  1. แท็บจัดการราคาทุนสินค้า (SKU Cost Master):
    • แสดงตาราง SKU ทั้งหมดของบริษัท มาตัง คอสเมติก จำกัด
    • สามารถคลิกแก้ไขราคาทุนต่อหน่วย (Unit Cost) ได้โดยตรง หรือเพิ่ม SKU ใหม่เข้าระบบ
    • *เมื่อแก้ไขราคาทุน ระบบจะคำนวณยอดกำไรของทุกคำสั่งซื้อใหม่แบบ Real-time ทันที
  2. แท็บค่าใช้จ่ายคงที่โรงงาน (Factory Fixed Costs):
    • บันทึกค่าใช้จ่ายรายเดือนของโรงงานแยกตามงวด (เช่น ค่าแรงพนักงานฝ่ายผลิต, ค่าน้ำประปา, ค่าไฟฟ้า, ค่าเช่าสถานที่)
    • ตัวเลขนี้จะถูกนำไปหักลบเพื่อหากำไรสุทธิสุดท้าย (Net Profit) และคำนวณจุดคุ้มทุน (BEP)
  3. แท็บอัตราค่าคอมมิชชั่นพนักงานขาย (Sales Commission %):
    • กำหนดเปอร์เซ็นต์ค่าคอมมิชชั่นของทีมไลฟ์สดหรือแอดมินขาย ระบบจะหักออกจากกำไรให้อัตโนมัติ

3.5 หน้าวิเคราะห์ขั้นสูง (🎛️ วิเคราะห์ขั้นสูง)

เครื่องมือสนับสนุนการตัดสินใจเชิงกลยุทธ์สำหรับผู้บริหาร:

  • แบบจำลองสถานการณ์กำไร (What-If Profit Simulator): ผู้บริหารสามารถทดลองเลื่อนสไลเดอร์เพื่อดูผลลัพธ์ล่วงหน้า เช่น:
    • หากปรับลดราคาขายลง 5% หรือ 10% จะต้องขายเพิ่มอีกกี่ชิ้นถึงจะได้กำไรเท่าเดิม?
    • หากต้นทุนวัตถุดิบเครื่องสำอางปรับเพิ่มขึ้น 15% บริษัทจะเหลือกำไรสุทธิเท่าใด?
    • หากเพิ่มงบประมาณยิงแอดโฆษณา 20% ผลกำไรจะเปลี่ยนแปลงอย่างไร?
  • การวิเคราะห์ความอ่อนไหว (Sensitivity Matrix): ตารางประเมินผลกำไรสุทธิตามระดับราคาและต้นทุนที่แปรผัน

3.6 หน้ารายงาน (📑 รายงาน)

ศูนย์กลางการจัดทำและส่งออกเอกสารรายงานทางการเงิน:

  • ส่งออก Excel (.xlsx): กดปุ่ม "📥 ดาวน์โหลดรายงานฉบับสมบูรณ์ (Excel)" เพื่อรับไฟล์สรุปผลที่มีชีตสรุปรายวัน, สรุปรายออเดอร์ (คอลัมน์ F, G, H), และสรุปรายบรรทัดสินค้าครบถ้วน
  • พิมพ์รายงานสรุปผู้บริหาร (Executive Summary): กดปุ่ม "🖨️ สั่งพิมพ์รายงาน / บันทึกเป็น PDF" เพื่อพิมพ์เอกสารสรุป 1 หน้า A4 สำหรับนำเข้าที่ประชุมผู้บริหาร

3.7 หน้าจัดการผู้ใช้งาน (⚙️ ผู้ใช้งาน)

ระบบความปลอดภัยและการจัดการบัญชี:

  • การเพิ่ม/แก้ไขผู้ใช้งาน: สร้างบัญชีใหม่ กำหนดสิทธิ์เป็น Admin หรือ Staff และเปลี่ยนรหัสผ่าน
  • ระบบ One-Click Backup: กดปุ่ม "📦 สำรองฐานข้อมูลทั้งระบบ (.zip)" เพื่อดาวน์โหลดไฟล์สำรองฐานข้อมูลเก็บไว้ ป้องกันข้อมูลสูญหาย
  • ระบบ Database Restore: อัปโหลดไฟล์ zip สำรองเพื่อกู้คืนฐานข้อมูลเดิมกลับมาได้ในคลิกเดียว

ส่วนที่ 5: การแก้ปัญหาที่พบบ่อย (Troubleshooting & FAQs)

ปัญหาที่พบ สาเหตุและแนวทางแก้ไข
ดับเบิลคลิก run.bat แล้วหน้าต่างเด้งปิดทันที ตรวจไม่พบ Python ในเครื่อง ให้ติดตั้ง Python 3.10+ จาก python.org และต้องติ๊กถูกหน้า "Add python.exe to PATH" ตอนติดตั้ง
แตกไฟล์ zip บน Windows แล้วฟ้อง Error เกิดจาก Windows Explorer ไม่รองรับชื่อไฟล์ภาษาไทย ให้ใช้ไฟล์ Matang_System_with_SampleData.zip ซึ่งตั้งชื่อไฟล์ภาษาอังกฤษทั้งหมด หรือใช้โปรแกรม 7-Zip/WinRAR ในการแตกไฟล์
อัปโหลดไฟล์ Excel แล้วไม่พบชีตข้อมูล ระบบรองรับชื่อชีตมาตรฐานของ TikTok Shop เช่น 'รายละเอียดคำสั่งซื้อ', 'Order', 'OrderSKUList', 'Order8', 'SKU', 'ads' ตรวจสอบว่าไฟล์ต้นฉบับไม่ได้ถูกเปลี่ยนชื่อชีตเป็นอย่างอื่น
ต้องการล้างข้อมูลเก่าออกทั้งหมด ไปที่หน้า "📤 นำเข้าข้อมูล" เลื่อนลงมาที่กล่องเลือกงวด เลือก "📊 สรุปรวมทุกงวดทั้งหมด" แล้วกดปุ่ม "🗑️ ลบข้อมูลทุกงวด" ข้อมูลจะถูกล้างออกจากระบบทันที
