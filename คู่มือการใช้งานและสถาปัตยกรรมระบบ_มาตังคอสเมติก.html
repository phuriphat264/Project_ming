ระบบคำนวณต้นทุนและวิเคราะห์กำไรขาดทุน TikTok Shop

บริษัท มาตัง คอสเมติก จำกัด (Matang Cosmetic Co., Ltd.)
ผู้พัฒนา: นายวรณ วิโคตร (รหัสนิสิต 67310177) | สาขาวิชาเทคโนโลยีสารสนเทศและวิทยาการข้อมูล มหาวิทยาลัยบูรพา
วัตถุประสงค์ของเอกสาร: เพื่ออธิบายรายละเอียดโครงสร้างระบบ สถาปัตยกรรมข้อมูล ขั้นตอนการทำงาน (Workflow) สูตรการคำนวณต้นทุน-กำไรตามหลักบัญชี และคู่มือการติดตั้งใช้งานสำหรับฝ่ายบัญชีและผู้บริหาร บริษัท มาตัง คอสเมติก จำกัด

1. โครงสร้างและการทำงานของระบบ (System Architecture)

ระบบถูกพัฒนาขึ้นในรูปแบบ Web Application แบบตอบสนองฉับไว (Interactive Single-Page Architecture) โดยใช้ภาษา Python 3.10+ ร่วมกับเฟรมเวิร์ก Streamlit และฐานข้อมูลแบบฝังตัว SQLite + Apache Parquet เพื่อรองรับการประมวลผลคำสั่งซื้อปริมาณมากระดับหลายหมื่นออเดอร์ต่อวินาทีได้อย่างราบรื่น

1.1 องค์ประกอบของระบบหลัก (Core Components)

  • Data Ingestion (core/loader.py): โมดูลนำเข้าและแปลงข้อมูล (ETL) สามารถตรวจจับและทำความสะอาดแถวหัวตารางที่ซ้ำซ้อนของ TikTok Shop โดยอัตโนมัติ (Header Auto-Recovery) รองรับทั้งภาษาไทยและอังกฤษ
  • Pipeline & Deduplication Engine (core/pipeline.py): เครื่องมือจับคู่และจัดกลุ่มคำสั่งซื้อ (Order-SKU Matcher) พร้อมกลไกป้องกันการคิดต้นทุนซ้ำ (1 COGS per Order ID) สำหรับออเดอร์ที่มีหลาย SKU หรือมีรายการคืนค่าจัดส่งย้อนหลัง
  • Financial Metrics Engine (core/metrics.py): โมดูลคำนวณตัวเลขทางบัญชี กำไรขั้นต้น กำไรสุทธิ Break-even Point และจำลองสถานการณ์ What-If
  • Database & Snapshot Storage (core/db.py): ระบบบันทึกข้อมูลงวดแบบ Columnar Storage (Parquet) แยกรายงวด พร้อมฐานข้อมูล SQLite เก็บโครงสร้างต้นทุนและบัญชีผู้ใช้งาน

2. สูตรการคำนวณต้นทุนและกำไร (Calculation Formulas)

การคำนวณในระบบอ้างอิงตรงตามโครงสร้างเอกสารรายงานทางการเงินของ TikTok Shop Seller Center เพื่อให้ตัวเลขทางบัญชีกระทบยอดตรงกับยอดเงินที่เข้าบัญชีธนาคารจริงของบริษัท:

ตัวชี้วัด / คอลัมน์ สูตรการคำนวณในระบบ คำอธิบาย
1. ยอดเงินโอนสุทธิ (F)
(Net Settlement)		 ยอดขายรวม - ค่าธรรมเนียมทั้งหมด - แอด GMV ยอดเงินจริงที่ TikTok โอนเข้าบัญชีบริษัท (หัก Transaction Fee, Commission Fee, ค่าส่งเรียบร้อยแล้ว)
2. มูลค่าต้นทุน SKU (J)
(SKU Cost Value)		 Net Qty × ต้นทุนต่อหน่วย (I) Net Qty = จำนวนขาย - จำนวนส่งคืน
คำนวณเฉพาะจำนวนชิ้นที่ส่งมอบสำเร็จ
3. ต้นทุนรวมคำสั่งซื้อ (G)
(Total Order Cost)		 ผลรวมของคอลัมน์ J ในคำสั่งซื้อนั้น มีกลไกป้องกันต้นทุนเบิ้ล: บันทึกต้นทุนสินค้าเพียงครั้งเดียวต่อ 1 Order ID แม้จะมีแถวซ้ำจากการคืนค่าส่ง
4. กำไรหลังหักแอด GMV (H)
(Order Profit)		 ยอดเงินโอนสุทธิ (F) - ต้นทุนรวม (G) กำไรจากการขายหลังหักต้นทุนสินค้าและค่าแอดโฆษณา GMV
5. กำไรสุทธิสุดท้าย
(Net Operating Profit)		 กำไรหลังแอด (H) - ค่าคอมฯ - ค่าใช้จ่ายคงที่ กำไรสุทธิทางบัญชีหลังหักค่าคอมมิชชั่นคนขาย และต้นทุนคงที่โรงงาน (ค่าแรง, ค่าน้ำ, ค่าไฟ)
6. จุดคุ้มทุน (BEP)
(Break-even Point)		 ค่าใช้จ่ายคงที่ ÷ อัตรากำไรส่วนเกิน (Margin) ยอดขายขั้นต่ำที่บริษัทต้องทำให้ได้เพื่อให้คุ้มกับค่าใช้จ่ายคงที่ของโรงงานในงวดนั้นๆ

3. เมนูและฟังก์ชันการใช้งานในระบบ (System Functions)

  1. หน้าหลัก (Home): สรุปภาพรวมผลการดำเนินงาน ยอดขายสะสม กำไรสุทธิรวม และสถิติสถานะของระบบ
  2. แดชบอร์ด (📊 แดชบอร์ด):
    • แบนเนอร์ฟันธงสถานะกำไร/ขาดทุน พร้อมจำนวนออเดอร์ที่ขาดทุน
    • การ์ดตัวชี้วัดหลัก 4 ตัว (ยอดชำระ F, ต้นทุนสินค้า G, กำไรหลังแอด GMV H, และกำไรสุทธิ)
    • กราฟแท่งเปรียบเทียบผลประกอบการรายเดือน (จัดกลุ่ม Categorical ชัดเจน)
    • กราฟวิเคราะห์แนวโน้มรายวัน (Daily Trend) สลับดูกำไรก่อน/หลังแอด GMV ได้
    • ตารางจำแนกกำไร/ขาดทุนตามราย SKU สินค้า และตารางตรวจจับออเดอร์ขาดทุน (Anomaly Detection)
  3. นำเข้าข้อมูล (📤 นำเข้าข้อมูล):
    • อัปโหลดไฟล์ Excel จาก TikTok Shop (รองรับการ Drag & Drop)
    • ระบบตรวจจับหัวตารางและกู้คืนโครงสร้างไฟล์อัตโนมัติ
    • ระบบเชื่อมรวมข้อมูลข้ามไฟล์/ข้ามเดือน พร้อมตัดข้อมูลซ้ำซ้อน
    • กล่องเลือกเปิดดูงวดเดิมที่เคยบันทึก หรือกดปุ่ม "🗑️ ลบงวด" / "🗑️ ลบข้อมูลทุกงวด" เพื่อล้างข้อมูล
  4. สินค้าและต้นทุน (📦 สินค้าและต้นทุน):
    • จัดการราคาทุนต่อหน่วยของสินค้าแต่ละ SKU (มีผลคำนวณใหม่แบบเรียลไทม์ทันที)
    • บันทึกค่าใช้จ่ายคงที่ของโรงงานแยกตามงวดเดือน (ค่าแรง, ค่าเช่า, ค่าน้ำ, ค่าไฟ)
    • กำหนดอัตราค่าคอมมิชชั่นพนักงานขาย (%)
  5. วิเคราะห์ขั้นสูง (🎛️ วิเคราะห์ขั้นสูง):
    • เครื่องมือจำลองสถานการณ์ต้นทุน (What-If Profit Simulator) ให้ผู้บริหารทดลองปรับ % ต้นทุน ค่าแอด หรือราคาสินค้าล่วงหน้า
    • การวิเคราะห์ความอ่อนไหวของผลกำไร (Sensitivity Analysis)
  6. รายงาน (📑 รายงาน):
    • ส่งออกตารางข้อมูลคำนวณครบทุกชีตเป็นไฟล์ Microsoft Excel (.xlsx)
    • พิมพ์รายงานสรุปผลการดำเนินงานผู้บริหาร (Executive Summary) แบบ Print to PDF
  7. ผู้ใช้งานและความปลอดภัย (⚙️ ผู้ใช้งาน):
    • จำแนกสิทธิ์ 2 ระดับ: Admin (ผู้บริหาร) และ Staff (พนักงาน)
    • รหัสผ่านเข้ารหัสแบบ Bcrypt ป้องกันการโจรกรรมข้อมูล
    • ระบบ One-Click Database Backup & Restore สำรองฐานข้อมูลทั้งระบบเป็น .zip

4. ขั้นตอนการติดตั้งและเปิดใช้งาน (Installation & Setup)

ความต้องการของระบบ (System Requirements):
  • ระบบปฏิบัติการ: Windows 10/11 หรือ macOS 12+
  • โปรแกรม Python 3.10 ขึ้นไป (ตอนติดตั้งบน Windows ต้องติ๊กถูก "Add python.exe to PATH")

ขั้นตอนการเปิดระบบ:

  1. แตกไฟล์ ZIP "ระบบคำนวณต้นทุน_มาตังคอสเมติก.zip" ลงในเครื่อง
  2. สำหรับผู้ใช้งาน Windows: ดับเบิลคลิกที่ไฟล์ ติดตั้งและเปิดใช้งาน_Windows.bat
  3. สำหรับผู้ใช้งาน Mac: ดับเบิลคลิกที่ไฟล์ เปิดระบบ_Mac.command
  4. ระบบจะสร้าง Virtual Environment และติดตั้งโมดูลที่จำเป็นให้อัตโนมัติในครั้งแรก จากนั้นหน้าเว็บจะเปิดขึ้นมาที่ http://localhost:8501 ทันที

ข้อมูลบัญชีเข้าสู่ระบบเริ่มต้น:

ระดับสิทธิ์ ชื่อผู้ใช้ (Username) รหัสผ่าน (Password) สิทธิ์การใช้งาน
ผู้บริหาร (Admin) admin admin123 เข้าถึงได้ทุกหน้า แก้ไขต้นทุน ลบข้อมูล จัดการผู้ใช้ สำรองระบบ
พนักงาน (Staff) staff staff123 เข้าดูแดชบอร์ด นำเข้าข้อมูล และส่งออกรายงาน
